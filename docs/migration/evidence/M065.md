# M065：Forge/Vite 开发与可运行 package

进入日期：2026-10-14，Asia/Singapore。任务：TASK-T065。

## 实现边界

Forge owns start/package；Vite bundles main、sandbox preload 与 renderer，TS strict typecheck 单独执行。没有独立 TS emit/watch 链或第二套默认构建链。单 sandbox preload 的 Electron external、main/preload `.cjs` 输出、Node/DOM 类型边界与共享 HTML/CSS 输入由 [CONTRIBUTING](../../../CONTRIBUTING.md) 维护。

package 内 Go binary 位于 platform resources；运行路径不依赖启动 CWD。具体开发/打包路径与依赖版本见 CONTRIBUTING 和对应 manifests。

## 验收结果

- Forge 构建、资源/maps、sandbox preload、严格类型检查、Go session/transport 与 list/history 测试通过。
- 类型错误、缺失/不匹配 compiler、错误平台 package 目标均按预期失败；资源恢复与 native watch 检查通过。
- macOS 原生开发验收检查 CSS HMR、TS/HTML reload、受控 bridge、stdio history 和所拥有的 backend/server 进程退出。
- 最终 `.app` 从独立 CWD 启动通过列表/历史场景；验证覆盖 branch/context、empty/error/retry、scroll/Thinking 重入、JSONL bytes/mtime 不变和正常关闭。包内容包含应用资源与独立 Go binary，没有 mock/prototype/旧 build/watch。
- Linux/Windows 实机、installer、签名与发行仍未验证，由对应平台/发行任务负责；全产品 parity、共享 UI 完整 TS 迁移也未在本任务完成。
