## 实现边界

- Forge 是唯一默认 start/package 管理者；Vite 是应用代码/资源 emit 与热更新管理者。
  TS7 仅 strict noEmit；Forge hooks 在 start/package 前运行类型检查和 host Go 构建。
  默认 build/watch、TS7 emit 和额外 esbuild preload 合并已退役，旧文件用 trash 删除。
- 保留 sandbox/contextIsolation/noNode、受控两项 preload 能力、sender/frame/精确 URL
  校验与原有 stdio RPC。Vite reload 只允许同一受信页面导航；其他 URL、弹窗、
  webview 仍拒绝。开发 CSP 仅增加 self/WebSocket；package connect-src 保持 none。
- renderer 直接 import 现有 tokens.css/sidebar.css；没有复制共享手写真源。
  Vite 输出 HTML、hash CSS/JS 与 TS source maps；main/preload 为 Forge 8 默认 CJS，
  preload 单文件只 external Electron。TS7 Bundler resolution 保持 Node/DOM 隔离。
- Go development 路径基于 app.getAppPath，package 基于 process.resourcesPath；
  backend 作为 extraResource 放在 app.asar 外。host platform/arch 显式写入 Go build，
  foreign package 目标被拒绝，避免装入错误架构 binary。此限制不代表已完成跨构建。
- 保留明确 session-dir、目录分层覆盖、只读 catalog/history、会话内滚动/展开、
  错误/重试和原 Go lifecycle。CSS HMR 保持 renderer identity/历史；HTML/TS 自动
  full reload 仍按原候选 reload 语义重新加载列表，不新增跨 reload 的会话 UI 持久化。
- main SIGTERM 接入正常 app.quit/backend shutdown，供 Forge main restart 使用。
  preload/main 热更新由官方插件配置启用；本次编辑实测覆盖 CSS/renderer TS/HTML，
  未单独实测 main/preload 编辑后的 restart/reload。

## 失败、修正与归因

- 首次 npm 元数据查询默认 ~/.npm cache 返回 EPERM；改用项目 tmp cache 后成功，
  未改变系统 cache 权限。依赖安装中 rolldown native binding 下载较慢，最终成功。
- 首次 Forge package 的 Electron download 连接被终止；明确设置官方支持的
  packager download.cacheRoot 到项目现有 cache 后重试成功，没有手工替换 Electron。
- 初次 HTML 上级 CSS link 在开发 HTTP URL 未加载，CSS HMR timeout（VVtlTv）；
  改为从 renderer TS import 原 CSS 真源，并添加 CSS asset declaration。
  最终 native 检查先断言共享 token 已加载，再实际原子编辑和检查背景/identity。
- CSS HMR 已通过时，Vite log 显示 entry.ts page reload，但窗口标题未更新
  （83VQ4F）；原 will-navigate 无条件 preventDefault 阻断 reload。允许精确相同
  pageURL 后 qzseaT 同一回归场景通过，另断言不同 URL 仍拒绝。
  回归场景在修正前实际失败、修正后通过；未修改旧会话行为断言来迎合新实现。
- 发现旧模块测试仍读取 desktop/dist/preload.cjs，已改读 .vite/build/preload.cjs；
  最终 6+7 项测试验证的是 Vite 产物，不使用残留旧 dist。
- npm 提示可选 fsevents install script 未获 allowScripts；未运行/绕过该脚本，
  本次 host Vite 实际 watch/HMR 仍通过。Node 26 对 tsx module.register 发出
  DeprecationWarning；测试退出为 0，不据此宣称其他 Node 版本已实测。
- dow claim 曾在跨调用后不再有效，guard 拒绝文档写入；重新认领再通过标准
  apply_patch 写入。未改 guard 或直接写源绕过。
