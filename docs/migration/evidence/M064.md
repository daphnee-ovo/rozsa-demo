## 官方发布与安装要求

- 官方 [TypeScript README](https://github.com/microsoft/TypeScript#installing) 将 `npm install -D typescript` 作为稳定版本入口；[v7.0.2 release](https://github.com/microsoft/TypeScript/releases/tag/v7.0.2) 的 GitHub API 返回 `name: TypeScript 7.0.2`、`draft: false`、`prerelease: false`。npm `typescript` 的 `latest` 实查为 `7.0.2`，repository 为 `microsoft/TypeScript`，可执行入口为 `bin/tsc`。本次使用正式版，不使用 `@typescript/native-preview` 或同名第三方 ts7 包。
- 精确锁定 `typescript@7.0.2`。安装包的 `bin/tsc` 导入 `lib/tsc.js`，通过官方 `getExePath` 解析 `@typescript/typescript-${platform}-${arch}/lib/tsc`（Windows 为 `tsc.exe`）。macOS arm64 实际安装 `@typescript/typescript-darwin-arm64@7.0.2`；`node desktop/node_modules/typescript/bin/tsc --version` 实际输出 `Version 7.0.2`。
- 官方 optional dependencies 包含 macOS x64/arm64、Linux x64/arm/arm64、Windows x64/arm64 等平台，lockfile 保留这些包及 integrity。不能用 `--omit=optional` 安装。只有 macOS arm64实际执行；包存在不代表 Linux/Windows native 已验收。
- 编译器包 engines 为 Node >=16.20.0；本候选因 Electron 安装工具依赖要求 Node >=22.12.0，已声明到 desktop engines。新增锁定 esbuild 0.25.12 自身要求 Node >=18。实际环境为 macOS/darwin arm64、Node v26.10.0、npm 11.19.1、Electron 44.7.0。

## 实际调用链与兼容性调整

用户明确要求不做向后兼容。main 改为 NodeNext/ESM，使用 `import.meta.dirname`；生成的 `dist/node/package.json` 明确为 `type: module`。没有旧 CommonJS main 分支、TS5/TS6 fallback 或全局 compiler discovery。

`npm --prefix desktop run typecheck` → `node scripts/build.mjs --typecheck` → 验证本地 compiler 包与精确锁定的 TS7 版本 → 本地 `node_modules/typescript/bin/tsc -p <main/preload/renderer config> --noEmit`。构建和 watch 使用相同本地 launcher 做 JS emit；没有调用旧 JS compiler API。缺失包、缺失 launcher、错误版本、类型错误均返回失败；watch 的编译错误保留明确失败状态，仅修正后报告 ready。单独 `build:resources` 不运行编译器。

TS7 初次使用原配置失败：main 报 TS5108，`moduleResolution=node10` 已移除；preload 报 TS6046（不支持 `module: None`）及 TS5102（`outFile` 已移除）。最终 main 使用 NodeNext；renderer 与 preload 使用 ES2022/Bundler。strict、ES2022 lib、sourceMap、inlineSources、noEmitOnError 以及原有 skipLibCheck 不变；没有扩大 any 或跳过原有检查。

preload 先由 TS7严格检查并 emit 到 `dist/preload/`，再由 esbuild **仅合并 emitted JS** 成 `dist/preload.cjs`。esbuild读取 TS7 maps，保留原 TS sources/sourcesContent。bridge/entry 改为显式模块导入，所有行为保持原契约。根据 [Electron ESM 文档](https://www.electronjs.org/docs/latest/tutorial/esm#sandboxed-preload-scripts-cant-use-esm-imports)，sandbox preload 当前没有 ESM context，需 bundler；`electron` 是唯一 external runtime require。这是当前宿主约束，不是向后兼容。

main/preload 仍只有 Node globals，renderer 仍只有 DOM globals。资源 bytes、HTML/CSS/renderer/main/preload 最终加载路径与 source maps 保持当前可运行切片。watch仍以 300 ms 内容轮询处理原子保存、资源修改、TS/config修改和错误恢复；renderer/HTML/CSS reload，main/preload 重启，Go 显式构建的规则不变。

tsx 4.20.6 保留为 module runtime test runner，依赖 esbuild/get-tsconfig；本次实际 lockfile 没有 transitive typescript 依赖。它不做产品类型检查或生产 TS emit；未重写 UI 或测试 runner。
