# M003：Electron 会话切换与只读历史恢复

进入日期：2026-10-13，Asia/Singapore。任务：TASK-T003；依赖 TASK-T002。

## 行为与身份

Go `LoadedSessions` 按 path 复用已打开 session；新 session 使用只读 `Open/Entries`。打开失败不替换当前 tab、不缓存失败，用户可显式重试。renderer 保存本切片的 scroll/Thinking 展开状态；迟到 success/error 不能覆盖当前 session。

三个身份保持不同：catalog ID 来自 header，session ID 来自 filename stem，transport ID 由 JSON-RPC 库关联。`.jsonl` dotfile 的 stem 为 `.jsonl`；RPC 参数、path、catalog ID 与 header identity 都显式校验，不假定这些 ID 相等。请求限制为 `{path,catalogId}`，main 校验自有窗口/main frame/页面 URL，preload 不暴露任意 IPC。只读操作不改 JSONL；错误透明显示并保留原历史，重试只由用户触发。

历史展示保留 active branch 上的 user/assistant/toolResult 顺序；有效模型上下文仍单独由 Go `ContextMessages` 提供。文本以纯文本渲染，不执行 HTML/Markdown。完整 image/tool details、stream 状态、运行 session 与跨 reload 状态同步不属于本切片。

## 回归与验收

- Go/TS 聚焦测试覆盖切换、空历史、读取失败与手动 retry、A→B→A、迟到结果、identity、历史/上下文差异、状态隔离、只读与进程退出。
- 首轮回归发现 Rust 对 `.jsonl` dotfile 保留 stem、Go 初稿却得到空 stem；新增 Go identity 测试先失败，修正后通过。
- 对照断言发现初稿错误地优先显示 `displayText`；修正为旧 UI 的 user `extractText(content)` 后通过。
- 真实 Go→TS 检查发现 `omitempty` 丢失合法空 tool name；新增 fixture 后修正并通过。
- macOS Electron 原生验收观察到列表选择、active branch/context 数、Thinking/scroll 重入、empty、非法 UTF-8 错误与 Retry、受限 bridge、bytes/mtime 不变及正常关闭。合成 bad 文件只由本次验收输入修复。
- 本项原生检查未使用用户人工观察；人工点击/键盘、Linux/Windows 实机、完整产品视觉等价与全产品功能仍未验证。

完整 Markdown/image/tool 呈现和运行状态、JSONL 写入/branch/cwd、实际 compaction 与模型 overlay 分属后续任务。本页结果仅对应当前只读历史切片。
