# M001：Electron→Go 会话列表切片

进入日期：2026-10-13，Asia/Singapore。任务：TASK-T001。

## 来源与行为

实现对照当前 Rust 会话管理、GUI `get_sessions`、消息 serde 与现有集成测试。Go `catalog` 读取显式配置的目录层，Electron main/preload/renderer 只提供受限列表访问；本切片不写 JSONL，不读取真实会话或凭据。

| 规则 | 保留行为 |
| --- | --- |
| metadata | 从有效 header/entry 读取 path、id、cwd、parent、created；最大 timestamp 的 session_info 决定名称，同时间不替换，最新缺失/null/空白名称清除显示名。 |
| 更新时间 | 取有效 entry timestamp 的字典序最大值；没有 timestamp 时使用文件 mtime。 |
| 消息统计 | 统计所有有效 message（含 toolResult）；首条非空 user 文本用于预览；user/assistant text blocks 以空格连接，toolResult 不纳入文本索引。 |
| 分层与排序 | 后层同 ID 覆盖前层，按 modified 字符串降序；同时间不同 ID 不承诺额外顺序。 |
| 缺失与损坏 | 仅 `.jsonl` 文件参与；缺失目录层为空，未配置目录返回 `No session directories configured`；无有效 header 的文件跳过，目录读取错误返回带路径的错误。 |
| 只读 | 读取不重写、追加或修复 JSONL；成功和失败用例核对 bytes 与 mtime。 |
| 失败处理 | malformed/未知 entry 按既有 Rust 规则跳过；目录和 backend 错误透明返回，不伪造空列表。 |

新增的 `TestCorruptUnicodeAndDuplicateHeader` 回归在修复前失败：Go 默认解码接受 lone surrogate、重复 header 与错误大小写。修正后 Go 对齐当前 Rust 规则；没有修改既有 Rust 测试来迁就实现。

## 验收结果与边界

- Go session/transport、TypeScript 类型检查、session-list 测试、候选 prepare 检查均通过。
- macOS 原生窗口实测列表排序、Unicode 预览、目录错误、空状态、受限 bridge 与正常关闭；Electron 和本次启动的 Go 进程均正常退出，合成输入 bytes/mtime 不变。
- Linux/Windows 实机运行、完整产品等价、完整原生 shell 与安装包仍未验证。
- 后续任务分别负责只读历史恢复、完整 JSONL 写入、运行中的产品能力与平台安装验收；本项不代表整体迁移完成。
