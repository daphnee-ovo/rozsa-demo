# M009 · 候选构建、source map 与资源 watch

进入日期：2026-10-13，Asia/Singapore。范围：TASK-T009；这是当前只读会话候选的构建增量，未完成整个迁移。正式状态通过 `dow task show TASK-T009` 查询。

## 对照来源与实现

- 旧 Tauri `crates/rozsa-gui/tauri.conf.json` 的 `frontendDist: ./frontend` 与 `build.rs` 直接装载现有前端目录。候选 T001–T003 已使用 `desktop/renderer/index.html` 和旧共享 UI 的 `styles/foundations/tokens.css`、`styles/features/sidebar.css`；本项延续这些来源，没有复制全部旧 UI。
- HTML 本身是当前候选的唯一页面模板；当前切片没有独立 template 文件。`desktop/scripts/resources.mjs` 将 HTML、两份 CSS 原样生成到 `dist/browser/renderer/index.html`、`dist/browser/ui/{tokens,sidebar}.css`，并生成 `dist/node/package.json` 的 CommonJS marker。原相对 CSS 和 JS 引用保持不变。shell build 与 npm build/watch 现在使用同一生成器。
- `tsconfig.shared.json` 提供 strict、ES2022、sourceMap、inlineSources、noEmitOnError；main/preload 使用 Node types 和不含 DOM 的 lib，renderer 使用 DOM、无 Node types。preload 保持 sandbox 所需的单个 `preload.cjs`，没有引入 require；main CommonJS 和 renderer ESM 不变。maps 带原 TS 内容并保留可解析的源码路径。
- 内容轮询每 300 ms 检查 TS/config/HTML/两份共享 CSS，覆盖原子保存与新增/删除 TS 文件。TS 变化串行重编译三组，资源变化只重生成资源；错误明确输出 `Watch build failed`，修正后继续。编译失败后任何后续变化都必须先成功重编译，才能报告 ready。退出信号关闭当前 compiler。
- watch 不管理 GUI 或 Go 重启；renderer/HTML/CSS 用窗口 reload，main/preload 须重启，Go 须显式构建。默认 `run.sh` 未改，仍启动 Tauri。`--resource-root`/`--out-dir` 只在本次测试中指向项目 tmp 隔离输入/输出。
- Go 继续拥有会话业务状态。此任务没有修改 RPC、session manager、产品数据或 renderer 功能；完整共享 TS、原型同源与最终目录搬迁仍由 T013/T060 承担。

## 实际环境与命令

macOS / darwin arm64；Node v26.10.0，npm 11.19.1，Go go1.26.6，Electron 44.7.0，TypeScript 5.9.3，tsx 4.20.6，dow 0.3.10。

```bash
bash devtools/build-migration.sh
npm --prefix desktop run typecheck
npm --prefix desktop run test:resources
npm --prefix desktop/js-tests test -- session-list
npm --prefix desktop/js-tests test -- session-history
bash devtools/run-migration.sh --prepare-only
npm --prefix desktop/js-tests run test:native-resources
```

`devtools/test-migration-build.sh` 作为本项 dow completion 的 Shell test 入口运行 fresh build、typecheck、资源测试和 prepare-only；没有进入全项目 TEST。新增资源测试位于 `desktop/js-tests/`，资源路径 smoke helper 位于 `desktop/build-smoke/`。未增加依赖，现有 lockfiles 不需改动。tsx 在 Node 26 输出已有 `DEP0205 module.register()` deprecation warning；检查仍成功，未压制警告。
