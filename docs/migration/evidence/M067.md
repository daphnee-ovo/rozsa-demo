## JSON 与依赖兼容性

Go 1.27 默认以 v2 实现支撑 `encoding/json`，保留该 v1 API 的行为；错误文本可能变化。现有 JSONL reader 的严格字段大小写、重复字段、Unicode/孤立 surrogate、整数、null、分支与 compaction 规则继续由已有测试约束，不替换为 v2 API 的默认语义。

T010 锁定 `go.lsp.dev/jsonrpc2 v1.0.1` 与间接依赖 `github.com/go-json-experiment/json v0.0.0-20260601182631-00ed12fed2a6`。实际 `go list` 显示：

```text
encoding/json: [v2_decode.go v2_encode.go v2_indent.go v2_inject.go v2_options.go v2_scanner.go v2_stream.go]
github.com/go-json-experiment/json: [alias.go]
github.com/go-json-experiment/json/jsontext: [alias.go]
```

`GOEXPERIMENT` 为空，未设置 `jsonv2` 或 `nojsonv2`；RPC 依赖通过其公开标准库别名使用默认引擎。Go 1.27.2 预检已通过，不需要升级或替换依赖，`go.sum` 保持不变。JSON-RPC 仍使用库原生 Conn/Stream，业务参数错误、notification、连接终止与 UI 接收取消规则保持 [M010](M010.md) 契约。
