与现有界面对齐

  • 不再虚构会话标题、对话气泡或新的产品文案；会话区、Status 卡片、Settings、聊天头部和正文示例按当前界面呈现。
  • 权限卡片沿用同一界面结构，按请求类型展示文件路径、Bash 命令或工具名与参数。信任选项仍是逐行直接操作；最终授权、拒绝或信任选择后立即关闭审批面板。
  • Permission Request 与 AskUserQuestion 的选项行静止时不显示边框，hover 时显示边框；返回圆形图标按钮保留自己的边框。
  • Permission Request 选项容器本身上下各留 12px；多行只增加整行高度，不压缩下方留白；快捷键块仍在整行垂直居中。AskUserQuestion 保持现有选项留白。Permission Request 选项内容左对齐并加粗，主操作快捷键 Y/T/N/H 显示在方框中且不加粗。
  • Permission Request 卡片变窄时，请求摘要和选项文字在卡片内部换行并完整显示，不得横向溢出或裁切；固定 24px 快捷键列始终在每一行内垂直居中，选项文字列占用剩余宽度。选项过多时只滚动选项区。
  • 正常与 hover 状态均不出现预期外的元素重叠；通知等明确设计的浮层允许遮挡。hover 边框不推动相邻内容，主操作与路径摘要之间保留明确间距。
  • 审阅说明和状态控件使用中文；产品窗口内保留现有英文文案，避免把翻译误作产品改动。

行为与恢复

  • 权限目标显示为 tmp/interruption-state-showcase/run-HdHEYs/permission-demo.txt；信任范围从文件、run-HdHEYs 目录、showcase 目录到 tmp/ 逐级扩大，末项去掉矩形边框，改用与 AskUserQuestion 操作按钮相同的圆形图标控件，Lucide ArrowLeft 居中并返回主操作。
  • 圆点表示待审批的权限请求数量，只剩一个待审批请求时不显示；每完成一个审批减少一个圆点。
  • Bash 请求展示完整命令与按命令前缀逐步放宽的 trust；选项超出可视高度时，只滚动选项区域，显示滚动条并支持 J/K。
  • 通用工具调用展示工具名、JSON 参数摘要、风险级别和该工具调用的 trust。
  • 权限最终操作点击后立即关闭面板并恢复输入框；这里不展示提交中或重试界面。T/H 进入提示或信任选项页不算最终操作。
  • 问题确认按钮在没有有效选择时置灰；选择 Other 后需填写回答才可确认，不出现校验错误提示。

键盘、焦点和请求身份

  • 权限主操作使用左对齐的 Y/T/N/H 方框快捷键；字母方框不加粗，右侧选项内容加粗。信任范围使用同款数字方框，文字左对齐。提示输入使用 Enter 提交、Escape 返回或取消；选项区聚焦时 J/K 上下滚动。
  • Permission Request 选项容器本身上下各保留 12px padding；文字按自然行高换行，换行只增加整行高度，不挤压下方留白。快捷键块独立垂直居中；选项行不设固定最小高度，行高由 12px padding 与内容（24px 快捷键列）决定，列表行不被压缩，超出时只滚动选项区。hover 状态保持相同的上下 padding 与 1px 边框宽度，不改变选项高度或文字留白。AskUserQuestion 保持现有选项留白。
  • Permission Request 在窄卡片中以 24px 固定快捷键列和可收缩文案列排版；长路径、命令与选项文案在面板内换行，保持完整。布局变化不能拉宽选项按钮、挤出或裁切文字，也不能移动快捷键的垂直中心。
  • 问题选项数字块在选项行内垂直居中并使用数字键；N/Enter 前进，D 完成。取消按钮为圆形 X 图标，与圆形确认按钮成对；无障碍名称仍为 Cancel。选择自定义回答后焦点进入输入框。
  • 切换 session 后再收到旧请求结果时，按原 sessionId 与 requestId 归属处理；它不能关闭或改动当前会话的面板。这是请求归属规则，不是一个界面状态。
