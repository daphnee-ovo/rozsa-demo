用户想要把 agent_loop.rs 的事件处理从 match 重构为 trait 分发。先读一下当前代码看看结构。当前的 run() 方法有个大 match 处理所有事件类型，需要拆成独立的 handler。

方案：定义 EventHandler trait，每个工具实现 can_handle() + handle()。AgentLoop 持有 Vec 按注册顺序分发。这样能消除巨型 match，提高可测试性。

需要注意 backward compatibility——确保现有的测试都通过。先 Read 当前文件，然后创建 handler.rs，最后 Edit agent_loop.rs。
